🟢 看多勝率

頭條=隔日結算:日報每天出新判斷,今天的判斷明天就被新一份日報取代,所以頭條量「當天判斷,隔日收盤對不對」。「可以買」→ 隔日收盤上漲 = 贏;「繼續抱」→ 隔日沒有跌破 -2% = 贏(續抱後上漲對持有者是好結果,故只罰下跌)。跟著抱更久的結果在上方 週/月/季 表,全部公開。

例:「台積電可分批接」→ 隔日收盤高於建議日 = 贏

🔴 看空勝率

日報示警「觀望 / 拉回 / 短期過熱 / 風險」(偏空)→ 隔日收盤真的沒漲(漲幅 <1%)= 贏(成功避坑);週/月/季結算門檻按時間放大(<2% / <4% / <7%)。

例:「NVDA 短期過熱建議觀望」→ 隔日沒漲算贏
我們不做這件事:不會在日報明確說「請在 X 元進場」「設停損 Y 元」——那是投顧的事,需要牌照,也容易變炒股嫌疑。我們只判讀方向 + 警示風險,進場價位由你自己決定。

每週自動更新:腳本從歷史日報抓出每一筆個股提及,自動分類為 A / C,並用 Yahoo Finance 拉 5 個交易日後的收盤價計算贏輸(建議的時間視角是 1-2 週,不拿單日雜訊評分)。因此最近 5 個交易日內的建議會顯示「結算中(第 N/5 日)」——尚未走完 5 日視窗、還在累積資料,並非卡住;滿 5 日後自動翻成贏/輸。 程式碼公開在 scripts/build_track_record.py。沒有任何人工後修——紀錄出來什麼就什麼。
