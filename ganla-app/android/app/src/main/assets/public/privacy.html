乾啦 隱私政策

最後更新：2026 年 5 月 23 日

一、我們不收集個人資料

「乾啦」不要求註冊、不收集姓名、Email、手機號碼、生日、付款資訊或任何身分識別資料。

二、本機儲存

App 使用瀏覽器 / 裝置的 localStorage 儲存以下資料，只存在你自己的裝置上、不會上傳：

  • 本機玩家名單（你輸入的暱稱）
  • 偏好設定：微醺友善模式開關、音效開關、是否已通過 18 歲確認
  • 多人連線使用的暱稱

清除 App 或瀏覽器資料即可刪除以上資料。

三、多人連線

當你使用多人連線功能時：

  • 4 碼房號與你輸入的暱稱會透過 WebSocket 傳送到伺服器（Cloudflare Workers + Durable Objects）以支援同房玩家間的即時同步
  • 遊戲狀態僅在房間活動期間暫存於記憶體，所有人離開後即刪除
  • 不記錄 IP、不長期儲存任何遊戲紀錄、不串接第三方分析平台

四、App 權限

App 僅使用以下系統功能：

  • 網路：載入頁面與多人連線
  • 震動（Android）：遊戲互動回饋
  • 音訊輸出：透過 Web Audio API 即時合成音效播放（不錄音、不存取麥克風）

不存取相機、相簿、位置、通訊錄、麥克風、藍牙、健康資料。

五、年齡限制

本 App 為 18 歲以上成年人設計。首次開啟時會要求年齡確認。請理性飲酒、未成年請勿飲酒、酒後不開車。

六、第三方

App 使用 Cloudflare 託管網頁與多人連線伺服器。Cloudflare 隱私政策請見：cloudflare.com/privacypolicy

不使用 Google Analytics、Facebook SDK、廣告 SDK 或其他追蹤技術。

七、廣告與內購

免費使用，無廣告、無內購、無訂閱。

八、聯絡

關於隱私問題請聯絡：hello@marketdaily.ai

Ganla Privacy Policy

Last updated: May 23, 2026

1. No personal data collected

Ganla does not require sign-up. We do not collect names, email, phone, birthday, payment info, or any identifying data.

2. Local storage

The app uses browser/device localStorage to save the following, stored only on your device, never uploaded:

  • Local player roster (nicknames you enter)
  • Preferences: soft drink mode, sound on/off, 18+ age confirmation
  • Display name used in multiplayer

Clearing app/browser data removes all of this.

3. Multiplayer

When you use multiplayer:

  • The 4-letter room code and your chosen display name are sent over WebSocket to our server (Cloudflare Workers + Durable Objects) to sync players in the same room
  • Game state lives in memory only during room activity and is deleted once everyone leaves
  • We do not log IP addresses, store game history long-term, or use third-party analytics

4. Permissions

The app uses only:

  • Network: to load pages and connect to multiplayer
  • Vibration (Android): tactile feedback during games
  • Audio output: Web Audio API synthesizes sounds locally; no microphone access

Does not access camera, photos, location, contacts, microphone, Bluetooth, or health data.

5. Age

This app is designed for adults aged 18+. An age gate appears on first launch. Please drink responsibly. Underage drinking is illegal. Don't drink and drive.

6. Third parties

Hosted on Cloudflare. Cloudflare privacy policy: cloudflare.com/privacypolicy

No Google Analytics, Facebook SDK, advertising SDK, or other tracking.

7. Ads & purchases

Free to use. No ads. No in-app purchases. No subscriptions.

8. Contact

Privacy questions: hello@marketdaily.ai
