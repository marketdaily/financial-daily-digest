# 乾啦 — 台灣喝酒遊戲 App

台灣人的喝酒遊戲全集。純前端 PWA（HTML/CSS/JS），可加到手機主畫面、離線可玩，之後可包成原生 App 上架。

## 內含遊戲（17 款 + 規則大全）

### 🎉 經典熱場
- 🎲 **派對指令** — 36 張在地指令卡，自動點名玩家（✅ 2+ 人）
- 👑 **國王遊戲** — 3D 翻牌動畫，A～K 各一條規則
- 🔥 **真心話大冒險** — 20 題真心話 / 20 題大冒險
- 🫵 **誰最有可能** — 數到三一起指人，最多票喝

### 🎲 骰子轉盤
- 🎰 **7-8-9 骰子** — 立體骰子翻滾，依總和決定公杯怎麼喝
- 🎲 **吹牛骰（大話骰）** — 傳手機看暗骰，喊注後開盅對帳（✅ 2+）
- 🎯 **命運轉盤** — 立體轉盤旋轉，conic-gradient 扇形 + 落點數學（✅ 2+）
- 🔢 **終極密碼** — 1–100 猜數字，範圍自動縮小

### 💥 刺激運氣
- 🔫 **俄羅斯輪盤** — 左輪 3D 轉輪，六發一彈
- 💣 **地雷陣** — 4×3 格輪流點，踩到地雷的喝
- 🧨 **定時炸彈** — 點燃引信後快傳手機，爆炸時拿著的喝（滴答加速）
- 🍾 **轉瓶子** — 3D 瓶身旋轉，瓶口指到誰誰接招（✅ 2+）

### ⚡ 反應對決
- ⚡ **手速王** — 反應時間測試（ms），偷跑記犯規，比完出排名（✅ 2+）
- 🧠 **記憶大考驗** — Simon 燈光順序記憶，越記越長，記錯喝
- ✊ **猜拳擂台** — 出拳對 AI，輸或平手喝
- 🎭 **比手畫腳** — App 出題＋40 秒倒數，沒人猜到演的人喝

### 🕵️ 動腦推理
- 🕵️ **誰是臥底** — App 發祕密詞，傳手機看詞、投票揪臥底（✅ 3+）

### 📖 規則大全
12 款線下玩法規則（啤酒乒乓、敲敲杯、369、射龍門、照相機、上樓梯下樓梯、摸鼻子…）

### 🌐 多人連線（共 9 款）
- 🎲 **多人搖骰** — 每人各自手機搖骰，server 同步開盅，最小的喝
- 🎴 **妞妞** — 每人 5 張暗牌（私訊送到自己手機），亮牌比點數
- 🐉 **射龍門** — 輪流上場，翻 2 龍柱、下注 1-5 杯、第 3 張驗證
- ❤️ **心臟病** — 即時搶拍對戰，喊到的數字翻出時最慢的吃牌
- 🃏 **抽鬼牌** — 自動配對、輪流抽鄰座，鬼牌在誰手上誰喝
- 💯 **十點半** — TW 撲克變體，比莊家近 10.5 分，輸的喝
- 🂡 **大老二** — 單張/對子/三條/順子/同花/葫蘆/鐵支/同花順，先出完贏
- ❤️ **撿紅點** — 配對收牌，紅心方塊最多贏，最少喝
- 🪢 **接龍** — 輪流出下一個點數（A→2→…→K→A 循環），沒牌就喝跳過

主機建房得 4 碼房號，朋友打開 ganla.pages.dev 輸入即可加入（最多 12 人）。後端 Cloudflare Worker + Durable Objects（`ganla-rooms`）+ WebSocket 即時同步。

## 視覺與互動

- **3D transform**：翻牌、立體骰子、實體轉盤、左輪轉輪、3D 瓶身
- **音效引擎**：Web Audio API 即時合成（無音檔依賴），可開關
- **彩帶特效**：勝利時觸發
- **震動回饋**：navigator.vibrate
- **首頁分類**：5 大類別 + 新遊戲徽章

## 功能

- **18+ 年齡確認**：首次進入需確認，符合 App Store 17+ 分級要求
- **微醺友善模式**：把「喝酒」改成「做大冒險」，不喝酒也能玩（呼應 sober-curious 趨勢）
- **玩家管理**：名單存 localStorage，下次打開還在
- **PWA**：含 manifest + service worker，可離線、可安裝到主畫面
- **手機優先**：深色派對風 UI，震動回饋

## 本機預覽

```bash
cd drink_game
python3 -m http.server 8901
# 開 http://127.0.0.1:8901
```

## 部署（Cloudflare Pages）

```bash
npx wrangler pages deploy drink_game --project-name ganla --commit-message "deploy ganla"
```

## 之後上架原生 App

PWA 程式碼不用重寫，用殼包起來即可：
- iOS / Android：用 [Capacitor](https://capacitorjs.com/) 包成原生專案送審
- 送審注意：標題保留「喝酒遊戲」字樣、設 17+ 分級、年齡確認頁已內建

## 檔案

```
drink_game/
├── index.html      畫面結構
├── app.css         樣式
├── app.js          所有遊戲邏輯與資料
├── manifest.json   PWA 設定
├── sw.js           service worker（離線快取）
└── icon.svg        App 圖示
```

> 改 app.css / app.js 後若瀏覽器沒更新，是 service worker 在快取 —— 把 `sw.js` 的 `CACHE` 版本號 +1 即可。
