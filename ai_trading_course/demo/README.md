# AI 交易工程 · 最小可動閉環 demo

一個**真的能跑**的交易工程閉環，給你（Delvin）邊看邊改、邊學工程。
配套教材：上一層的《AI 交易工程地圖》PDF + 《動手實作課》PDF。

## 它做什麼

把《地圖》第一部的九階段，濃縮成一條可執行的最小管線：

```
FinMind 取台股日線 → MA 交叉訊號 → 向量化回測(扣真實成本)
   → 驗證(walk-forward + Deflated Sharpe + 多重檢定示範)
   → 風控(1% 風險式部位大小) → 今日 paper 下單指令
```

**重點不是「賺錢」，是讓你親手看到「驗證怎麼殺掉一個看似漂亮的策略」。**

## 怎麼跑

```bash
cd ~/Delvin-agent/ai_trading_course/demo
python3 run.py
```

第一次會打 FinMind 抓資料並快取到 `cache/`，之後秒跑。
（依賴：requests / pandas / numpy / scipy，winrig 已裝。）

## 檔案地圖（對照《地圖》的階段）

| 檔案 | 對應階段 | 做什麼 |
|------|----------|--------|
| `config.py` | — | 集中設定（標的/期間/參數/成本），**改這裡就好** |
| `data.py` | 1-2 資料/清洗 | FinMind 抓台股日線 + 本地快取 + 清洗 |
| `strategy.py` | 3-4 特徵/訊號 | MA 交叉訊號（`shift(1)` 防 look-ahead）+ ATR |
| `backtest.py` | 5 回測 | 向量化算每日報酬，**進出場扣手續費+稅+滑價** |
| `validation.py` | 5 的靈魂 | Sharpe / **Deflated Sharpe** / walk-forward |
| `risk.py` | 6 風控 | 依停損距離反推張數，單筆風險固定 1% |
| `paper.py` | 7 執行 | 把訊號+風控變成「今天該怎麼下單」的 paper 指令 |
| `run.py` | 閉環 | 串起全部，印出誠實報告 |

## 你會看到的誠實結果

跑出來你會看到（這正是要教的）：

1. **單一參數 MA20/60 常輸 Buy & Hold** —— 簡單技術策略在台股大型股沒有穩定 edge。
2. **掃 47 組參數挑最好的 Sharpe 看起來很神（>1.0）**，但 `DSR` 把「你試了 47 次」打折後就縮水 —— 這就是 data snooping / 過擬合。
3. **walk-forward 樣本外更殘酷**（2454 甚至變負）—— 沒看過的年份才是真相。
4. **paper 指令會老實說「1% 風險買不起台積電一整張」** —— 風控的真實限制。

> 對照你自己的 `trading_bot`：當年「Sharpe 1.58 的 pair trade」就是栽在這——窄窗口 + 挑最好那組。這個 demo 用 30 行讓你重看一次那個陷阱。

## 練習（從這裡開始改成你的東西）

1. **換標的/期間**：改 `config.UNIVERSE`、`START/END`。
2. **換策略**：在 `strategy.py` 加一個新訊號（RSI、突破、動能），看它過不過驗證。
3. **接 LLM 特徵**（《地圖》第二部）：把新聞情緒分數當成額外進場過濾條件，再跑一次驗證——**情緒有沒有真的加分，用 DSR 說話，別用感覺**。
4. **接真券商**：把 `paper.py` 的指令改送 ccxt（加密）或 Shioaji（台股）——但永遠先 paper 跑夠久。

## 鐵律（貼在螢幕上）

- 數字交給程式，文字交給 LLM。
- 任何策略上線前：walk-forward + DSR + 真實成本 + 先打敗 Buy&Hold。
- 記得「你試了幾次回測」。
- 沒有聖杯，只有閉環。
