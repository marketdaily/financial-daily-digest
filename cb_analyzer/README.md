# 台股 CB 拆解分析系統 (cb_analyzer)

輸入一個代碼 → 自動拉現股、算出 CBAS 拆解全套定價、槓桿、情境損益與評分。
資料來源:老闆每期的「CB發行案件更新」Excel。

## 用法

```bash
cd cb_analyzer

python3 cb.py 8112            # 單檔全套分析(可給股票代碼 8112 / 債券代碼 811211 / 名稱「至上」)
python3 cb.py --rank          # 所有已定價 CB → 拆解吸引力排序(看哪檔最值得買)
python3 cb.py --rank --html   # 同上,並輸出 report.html 玻璃卡片儀表板(瀏覽器打開)
python3 cb.py --list          # 列出資料庫全部案件(● 已定價 / ○ 條件未定)
python3 cb.py --update 新檔.xlsx   # 老闆給新一期 Excel,重建資料庫

# 即時報價(2026-07-07 起預設開啟,免旗標):現股+CB 百元報價自動用 TWSE MIS 即時
python3 cb.py 8112 --watch        # 盤中即時監看:每 20 秒刷新報價重算全套(--watch 10 改間隔,5~600秒)
python3 cb.py 8112 --live         # 加試 FinMind/TPEx議價板深源(MIS 抓不到 CB 價時的備援)

# 券商 CBAS 報價單輸入(拿到報價單就填,全鏈路以真實報價為準,零誤差):
python3 cb.py 8112 --premium 5.5 --interest 2.2   # 權利金百元報價 5.5 + 每年利息 2.2%

# 主動式 ETF 持股監控(cron 每天 08:35 自動更新帳本;單檔報告會自動附):
python3 cb_etf_watch.py 5289      # 查哪些主動式 ETF 持有 5289 + 近30日加減碼異動
python3 cb_etf_watch.py --update  # 手動立刻重抓全部 00xxA ETF 持股並 diff

# 元大 CBAS 報價單自動套用(2026-07-07):許乃方每週寄的「CB資產交換選擇權報價表」
# 信件本文內嵌「下周拆解標的」表(百元報價/折現率/選擇權到期日/元大版轉換價/CB市價/波動度)
python3 cb_yuanta.py --ingest <信件內容檔>  # 入帳本;單檔分析自動套用(--premium 手動輸入仍優先)
python3 cb_yuanta.py --list               # 帳本內全部元大報價;>14天視為過期不自動套用
# 元大版轉換價 vs 系統差>0.5% → 自動警示建議 --set-conv(權威交叉源)

# 事件日曆 + 轉換價紀律(2026-07-07):
python3 cb.py --calendar          # 未來60天:詢圈/申報生效/掛牌/🔑可拆解日/賣回/到期 倒數
python3 cb_conv_watch.py --alerts # 未解決的「轉換價格調整」公告警示(MOPS 重訊,cron 每日掃)
python3 cb.py --set-conv 811211 95.3  # 查到最新轉換價後人工覆寫(報告顯示覆寫日期+原值)
# 單檔報告自動附:籌碼(流通餘額/已轉換%/票面,TPEx 每日檔)+近期事件倒數+轉換價調整警示

# 臨時覆寫假設(優先於 cb_config.json):
python3 cb.py --rank --swap 0.025 --rf 0.015 --vol-short 0.2 --vol-long 0.8
```

長期參數改 `cb_config.json`(資金成本/無風險利率/波動加權/TCRI 信用利差),不用動程式。

換新一期 Excel:把新檔丟進 `/mnt/c/Users/USER/Downloads/`,跑 `python3 cb.py --update 路徑`,
其餘指令不用改。

## 老闆的拆解硬門檻(最優先,不是加分是及格線)

**TCRI 須為 3 或 4** 且 **發行量 ≥ 雙位數億(10億)**,兩條同時滿足才值得拆解:
- TCRI 3-4 → 信用夠好,**銀行才肯承做資產交換(ASW)**;5 以上銀行不收債券底或收很貴,拆不了。
- 發行量 ≥10億 → 有流動性、進出得去,資產交換台吃得下。

任一不過 → 直接淘汰(不管模型評幾分)。`--rank` / HTML 會分成「✅符合 / ⚠不符 / 👀待定價觀察」三區。
門檻可在 `cb_config.json` 的 `elig_tcri` / `elig_min_size` 調。

## 模型(每檔 CB = 債券底 + 轉換選擇權)

- **轉換價值 parity** = 現股價 ÷ 轉換價 × 100
- **債券底** = 賣回/到期金額(YTP/YTM)按「無風險利率 + TCRI 信用利差」折現
- **轉換選擇權** = Black-Scholes 買權(標的股價、轉換價、年期、歷史波動率),每張 CB 含 100/轉換價 張
- **理論 CB 價** = 債券底 + 選擇權,對比發行價 → 是否便宜
- **隱含波動率** = 由**真實承銷/競拍清算價**反解(備註的承銷價/低高標),對比前瞻波動 → 選擇權便宜或貴
- **前瞻波動率** = EWMA(短期 regime)與 120 日(長期均值回歸錨)加權;CB 選擇權存續長故偏重長期,降低近期飆高偏誤
- **拆解槓桿** = parity ÷ 權利金;下檔最多賠光權利金(債券底已賣斷給銀行),上檔吃股票漲幅
- **情境損益** = 股價 ±10/20/30% 下對權利金本金的報酬率
- **綜合評分 0–100** = 波動率價差30 + 理論edge20 + Delta甜蜜點20 + 信用15 + 流動性10 + 槓桿5

## 假設參數(在 `cb_core.ASSUMPTIONS` 調整)

- 無風險利率 rf = 1.3%
- 資產交換 spread(銀行融資) = 2.0%/年
- 波動率取樣 = 60 交易日
- TCRI 信用利差表:1→0.8% … 6→3.8% … 9→8.2%

## 重要提醒

- 隱含波動已用**真實承銷/競拍清算價**反解(競拍承銷價 > 低高標中值 > 詢圈固定%);這版已誠實。
- 浮現的可操作規律:**詢圈固定價案子才有便宜選擇權可拆**,競拍多半把波動價值吃光(清算價拉高 → 隱波 ≥ 前瞻 → 評分自動降)。例:萬潤六競拍到 140 → 隱波 100% > 前瞻 88% → 評分 42「避」。
- 評分當**篩選排序**用,不是直接下單訊號。融資、交易稅、賣回時點、流動性折價未精算。
- 最終進場前仍要人工核對承銷條件與資產交換報價。

## 發行人強贖(130%)進定價(2026-07-07)

台灣 CB 標準條款:收盤價**連續30營業日 ≥ 轉換價130%** → 發行人可強制贖回 → 持有人被迫轉換,上檔被封。
這是 Parisian 型條款,用標準近似「有效障礙上移」:B_eff = 轉換價 × 1.30 × exp(0.5826·σ·√(30/252)),
以 Reiner-Rubinstein up-and-out + 觸價轉換 rebate 閉式定價(`backtest/test_call_barrier.py` 蒙地卡羅
夾擠驗證,6案例全過)。選擇權/理論價/隱波/情境全鏈一致;報告同時顯示「無強贖上界」供比對。
影響:舊純 BS 系統性高估選擇權(至上11 34.7→23.8),評分整體下修=誠實化。`call_adjust:false` 可退回舊口徑。

## 元大郵件全自動(cb_mail_ingest.py,需一次性設定)

`.env` 加 `GMAIL_USER` + `GMAIL_APP_PASSWORD`(Google 應用程式密碼)後,cron 每日 08:35 自動:
①選擇權報價表 → 入報價帳本 ②CB發行案件更新 xlsx → 自動重建資料庫 ③基本資料表 → 存檔備查。
未設定時靜默跳過。手動:`python3 cb_mail_ingest.py --run --days 30`(首次回補)。

## 即時報價(2026-07-07 上線)

**TWSE MIS API**(免費免 token,約 5 秒快照,上市/上櫃/CB 都有)是現股與 CB 百元報價的第一來源:

- 現股價:盤中=即時成交/中價(報告標「即時 HH:MM:SS」),收盤後=當日收盤(標「收盤 日期」)。波動率仍用日線算,即時 tick 不進波動率。
- **CB 百元報價**:債券代碼直接查 MIS(CB 在櫃買等價系統交易),含買賣五檔第一檔。有市價 → 隱波/權利金/評分全改用**市場隱波**;抓不到 → 透明退回承銷價隱波。
- 快取 15 秒(`.quote_cache.json`),`--rank`/網頁全表掃描批次抓不會狂打。
- `--live` 現在的意思=加試深源備援(FinMind CB dataset 需 `FINMIND_TOKEN`、TPEx 議價板),MIS 抓不到才需要。
- 網頁版(`cb_server.py`,port 8911)同步受益:沒手動帶 CB 價時自動用 MIS 即時價。

## 券商目標價紀律(2026-07-07 起)

`company_intel.json` 的 target_price **必附 broker(來源券商)+ target_date + source_url**;
顯示端:缺券商 → 標「⚠ 來源不明,勿引用」;逾 90 天 → 標過期需重查;無出處連結 → 標「新聞轉述」。
目標價多為新聞轉述非原始報告,查證以兩則獨立報導互證。

## 主動式 ETF 持股監控(cb_etf_watch.py)

全部 00xxA 主動式 ETF(清單動態拉 FinMind,新發行自動納入)每日全持股快照(MoneyDJ,資料日 T-1),
與前份 diff → **新進/剔除/加碼(權重+0.5pt或股數+20%)/減碼** 事件記 `.etf_holdings/events.jsonl`。
cron 每天 08:35 自動跑(`~/.marketdaily-fallback/cb_etf_watch_runner.sh`);單檔報告自動附
「🎯 主動式 ETF」區(哪些 ETF 持有+近30日異動)。防呆:原本有持股突然全空=疑似來源異常,保留舊快照不產生假「全部剔除」。
主動式**基金**(月揭露,lag 大)暫不做;投信整體買賣超已在市場情報的法人流向裡。
