## 1. 工具選擇:CBAS 權利金端優先,現券次之

| | CBAS 拆解(買權利金端) | 直接買 CB 現券 |
|---|---|---|
| 最大虧損 | 權利金全額(進場即知,真凸性) | 跌到債底(信用惡化時債底會塌) |
| 槓桿 | 4-7x(清單 lev 欄) | ~1x,一張 10-11 萬起 |
| 對手風險 | 券商(元大等) | 發行公司信用(TCRI 5-7 全是中弱) |
| 報價 | 許乃方週報價單(cb_yuanta.py 已 ingest) | 市場薄,MIS/議價板 |

**預設走 CBAS**:凸性論點本來就是「選擇權被賤賣」,直接買被賤賣的那一段,信用尾巴留給券商。
現券只在 CBAS 無報價、且 TCRI≤6、且 parity≤95(債底仍有意義)時考慮。

## 2. 入場資格(全部要過,缺一不進)

1. **凸性區**:parity 75-100。parity>105 = 股票替身(威宏三 108、萬旭 delta 1.15 → 剔除),
   要方向曝險去買股票,別付 CB 溢價。
2. **便宜度**:vol_edge ≥ +25%(實現波動 − 反解隱波)。⚠️ 高 HV 可能是事件性暴漲(不可持續),
   進場前看 v60/v120 是否也支撐(短長期波動都 > 隱波才算穩)。
3. **信用**:TCRI 5-6 全額資格;TCRI 7 額度減半且需 cb_intel 無未解決警示。
4. **真實報價**:承銷價定價≠可成交價。買前必跑 `cb.py <code> --watch` 拿實價重算便宜度;
   CBAS 以元大報價單為準(>14 天過期不用),權利金報價使便宜度縮水 >1/3 → 棄單。
5. **可拆解日已到**(`cb.py --calendar` 的 🔑),未到=只掛觀察。

以 2026-07-22 清單套用:合格=雙鍵二(4764)、一詮七(2486)、廣閎科一(6693)、巨漢一(6903)、
增你強五(3028);大東電一(1623) TCRI 7 減半;昶昕一 parity 75 壓線觀察;
剔除=威宏三/萬旭/安國(凸性耗盡或負便宜度)、擎亞三/雲豹(便宜度 <25%)。

## 3. 部位規則(以 300 萬本金計)

- **總權利金預算**:資金的 15% = 45 萬(=最壞情境全部歸零虧 15%,對應 30-40% 胃納的一半,
  留另一半給期貨線)。
- **單券上限**:總預算的 1/3 = 15 萬權利金;TCRI 7 → 7.5 萬。
- **最少分散 3 券**(信用事件是個券獨立事件,一顆雷不能帶走整個彈藥庫)。
- **分批**:每券分 2 批(1/2 + 1/2),第二批只在①現股回檔使 parity 掉 5 點以上 或
  ②新一期報價單便宜度仍 ≥25% 時加。
- 小規模券(≤5 億)流動性上限:單券持有 ≤ 發行量 0.5%(5 億=250 萬面額=25 張 CB 對應的權利金),
  掛限價不追價。

## 4. 出場紀律(寫死,不靠盤感)

1. **信用事件=無條件出**:TCRI 降級、MOPS 重訊(掏空/違約/重大虧損)、`cb_conv_watch.py --alerts`
   未解決警示、財報連兩季惡化。虧損出也要出——債底是紙上的,信用塌了就沒有底。
2. **凸性耗盡=獲利了結**:parity ≥ 120 或 delta ≥ 0.8 → 賣出/轉股,把資金滾回清單下一檔便宜凸性。
   (賺的是「凸性重新定價」,不是抱股票。)
3. **時間出場**:CBAS 選擇權到期前 60 天未觸發 1/2 → 評估 roll 或了結,不留到期限最後被 theta 吃。
4. **論點失效**:vol_edge 轉負(隱波升/實波降)且 parity<90 → 出一半,再惡化出清。

## 7. 誠實 caveat

- 隱波是**承銷價反解**不是市場成交 IV;12/68 檔可定價=樣本偏承銷條件已定的新券。
- 便宜度最高的通常最小規模(雙鍵二 5 億)=進得去出不來的風險,§3 流動性上限是硬線。
- 整池 TCRI 5-7,無投資級——這是「信用弱所以選擇權被賤賣」的硬幣另一面,分散+CBAS 結構
  是唯一防禦,不要因為便宜就單押。
- 本計畫未經回測驗證「vol_edge 高→未來報酬高」的橫斷面關係(n=12 不夠);它的依據是
  結構定價(買便宜的凸性),不是統計 edge。定位誠實:這是價值型押注,不是量化訊號。
