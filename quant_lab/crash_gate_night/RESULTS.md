# 外盤重挫閘·台指期夜盤軟化層回測(2026-07-21)

## 源起
2026-07-21:前日 KOSPI -6.4%/-4.5% 連兩日觸發硬閘,早報全面喊防守,台股當日大反彈 +3.89%
→ 硬閘 false positive。夜盤(前日 15:00~當日 05:00 收盤,早報 06:20 生成時已定案)其實已反彈 +0.79%。

## 資料與方法
- 台指期 TX 一般+盤後時段日行情:期交所 futDataDown,2017-05-15(夜盤上線)~2026-07-21
- 夜盤報酬=當日盤後收盤 vs 前一一般時段同月合約收盤(取盤後成交量最大月份);^TWII/^KS11/^SOX=Yahoo 日線
- 觸發定義與 analyzer._crash_gate 相同(SOX昨收<=-3% 或 KOSPI昨收<=-4%),無前視
- **門檻預先登記**:主檢定=夜盤>=0,穩健性=夜盤>=+0.5;採納條件=尾部機率回到接近基礎率且均報酬非負

基礎率:全樣本 2,233 交易日 P(<=-3%)=1.43%。年代穩定性(>=0 桶):2017-20 均+0.97%、2021-23 +0.08%、2024-26 +1.34%。

## 裁決
- 主檢定(>=0)尾部 4.2% 未達採納條件(唯一漏網 2018-10-11 夜盤僅+0.03% → -6.31%,落在邊界帶)
- **採納兩預登記候選中較嚴的 +0.5%**(保守方向的擇一,非事後掃參):該桶 0 次大跌、最差 -0.88%、三年代皆正
- 三大崩盤日 sanity:20240805(-8.35%)/20250407(-9.70%)/20260717(-6.47%)夜盤皆約 -2% → 全部維持硬閘 ✅
- 20260721 夜盤 +0.79% → 軟化 ✅(事故日本身被修復)

## 落地(analyzer.py + data_fetcher.py,同 commit)
- `fetch_tx_night()`:主源=期交所 CSV(與回測同基準)、備援=期交所 MIS API;只在早報時窗(TW 04-09)計算;兩源皆敗回 {} → fail-closed 硬閘
- `_crash_gate` 加 `softened`(夜盤 >= CRASH_GATE_NIGHT_SOFTEN=+0.5):不強制 risk_off(-2→-1)、不降級 buy 徽章、prompt 改「不必全面防守,買進分批/條件單,跌破夜盤低點轉回防守」
- forward_ledger.jsonl:每次觸發記(硬閘/軟化 × 當日結果),累積 10 次後覆盤門檻
