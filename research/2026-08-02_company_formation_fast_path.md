# 台灣一人有限公司最快設立路徑(2026-08-02 現行)

研究日:2026-08-02(週日)。目標:8/15 前拿到統編(8/21 FinTech Taipei 送件前設立完成)。
方法:官方網站直抓(WebSearch 額度罄改 DuckDuckGo HTML+WebFetch)+經濟部 GCIS 開放資料 API 撞名實查。
定位:僅整理事實與行情,非法律/稅務意見。

---

## 0. 結論(最快路徑)

**建議:代辦(記帳士/會計師/線上服務)為主、自己只跑「自然人憑證+銀行」兩件事。**
自辦與代辦的官方審查天數相同(預查 1 日、設立登記 1 日為原則),差別在文件正確率與補正風險——時間緊時代辦一次過的價值最大。全案唯一不可控變數是**銀行籌備處帳戶開戶**(當天~數個工作天,個別銀行審核可長達 14 個工作天,見 §2 步驟 3)。

**預估時程(8/4 週一啟動)**:

| 日期 | 動作 |
|---|---|
| 8/4(一) | 戶政事務所辦自然人憑證(當場核發,250 元)→ 委任代辦簽約 → 當天線上送名稱預查(150 元) |
| 8/5(二) | 預查核准(審查以 1 日為原則);預約銀行開戶 |
| 8/6(三) | 銀行開「○○有限公司籌備處」帳戶+存入資本額(本人親跑,帶預查核准函+雙證件+印章) |
| 8/7(四) | 會計師資本額查核簽證(行情 3,000–5,000 元,1–2 天;代辦全包方案通常含) |
| 8/8(五) | 一站式線上送:設立登記+稅籍登記+健保投保單位(設立規費線上 700 元) |
| 8/11–8/12 | 核准 → **取得統一編號**(設立登記處理期間 1 日為原則+收發文時間) |
| 8/12–8/15 | 緩衝(補正/銀行延遲用) |

順利情境 **8/11–8/12 拿統編**,對 8/15 有 3 個工作天緩衝。若銀行開戶卡關(部分銀行審 5–14 工作天)才會踩線——所以 8/5 就要預約銀行,並選「當天可開籌備戶」的行庫(傳統公股行如台銀/華南/一銀對籌備戶最熟;數位帳戶/外商不收籌備戶)。

## 1. 流程與天數(逐官方來源)

### 1.1 名稱預查
- 申請方式:線上(一站式 onestop.nat.gov.tw)/郵寄/臨櫃(商業發展署南投辦公室)。
- 規費:**線上 150 元;郵寄/臨櫃 300 元**。
- 審查:**「1 日為原則」**(不含補正期間)。
- 核准保留:**6 個月**(可延展 1 次 1 個月)。
- 來源:經濟部工商輔導中心申辦說明 https://www.cto.moea.gov.tw/web/application/detail.php?id=347 ;一站式規費表 https://onestop.nat.gov.tw/oss/web/Show/workFlowApply_T.do

### 1.2 章程/文件
- 一人有限公司文件極簡:章程(唯一股東兼董事)、股東同意書性質文件、負責人身分證影本、公司大小章、登記地址使用同意(租約或房屋使用同意書+最近房屋稅單影本,實務要求依地方主管機關)。
- 一站式線上流程:自然人憑證登入 → 輸入基本資料 → 負責人線上簽章 → 上傳應備書件(來源同上 onestop 頁)。

### 1.3 資本額存入與驗資(2026 現行:一人公司也要)
- **公司法第 7 條:「公司申請設立登記之資本額,應經會計師查核簽證;公司應於申請設立登記時或設立登記後三十日內,檢送經會計師查核簽證之文件。」**——有限公司不分大小、不分資本額,一律要會計師資本額查核,**無金額門檻豁免**。來源:全國法規資料庫 https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0080001&flno=7
- 細節依「會計師查核簽證公司登記資本額辦法」(最後修正 2018-11-08):現金出資檢附送金單影本,無送金單者以存摺/對帳單/查詢單影本替代。來源:https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0080021
- **加速要點:§7 允許「設立登記後 30 日內」補送簽證文件**——理論上可先送設立登記再補驗資報告;實務上代辦多半同案併送(驗資只要 1–2 天,不是瓶頸)。
- 驗資簽證行情:**約 3,000–5,000 元起**(元方聯合會計師事務所 https://www.excelcpa.com.tw ;出任務行情頁 https://www.tasker.com.tw/price/cpa-audit 列 3,000 起)。

### 1.4 設立登記(線上 vs 紙本)
- 規費:**按章程資本總額每 4,000 元收 1 元,未達 1,000 元以 1,000 元計;線上申請減收 300 元**(資本額 10 萬或 50 萬都是最低級距 → 線上 700 元/臨櫃 1,000 元)。來源:onestop 規費表(同上);公司登記規費收費準則 https://law.moea.gov.tw/LawContent.aspx?id=FL011293
- 處理期間:**「公司設立登記申請案:1 日」**(我的 e 政府 https://www.gov.tw/News_Content_2_343201 ;臺中市經發局 FAQ 亦載「處理期限及領件時間:1 日」https://www.economic.taichung.gov.tw/16103/16461/18224/589494/ )。官方一覽表:https://gcis.nat.gov.tw/F/t70017 (Word 檔,Big5 編碼,本次抓取部分亂碼,天數以上列兩來源為準)。實際含收文/派文/發文,抓 1–3 個工作天。
- 一站式可**一次串辦**:名稱預查 → 公司設立登記 → 稅籍登記(原營業登記,免費)→ 勞/健保投保單位成立(免費)。來源:onestop 流程頁(同上)+GCIS 線上企業開辦 https://gcis.nat.gov.tw/mainNew/subclassNAction.do?method=getFile&pk=19

### 1.5 統編核發
- 統一編號於**設立登記核准時配賦**(核准函+登記表即載統編);稅籍登記隨後由國稅局處理(可能有營業地址勘查,但不影響統編已到手)。
- **全程最快實際天數:約 5–8 個工作天**(預查 1 + 銀行 1–3 + 驗資 1–2 + 設立 1–3),與代辦業者普遍宣稱一致;瓶頸=銀行。

## 2. 線上自辦條件

1. **必須有憑證**:一站式線上申辦「簽章作業須使用自然人憑證或工商憑證」(設立前沒有工商憑證,所以實質上=**必須自然人憑證**);讀卡機必備。搜尋結果另提到行動身分識別(TW FidO)部分流程可用,以現場實測為準。來源:onestop 流程頁(登入=「自然人憑證…輸入 PIN CODE 後登入」)。
2. **沒有憑證的替代**:自然人憑證**戶政事務所臨櫃當場核發**(本人+身分證正本+250 元,約 10 分鐘)——不是瓶頸,週一早上就能辦。來源:內政部憑證管理中心 https://moica.nat.gov.tw/rac.html ;桃園中壢戶政 https://www.zhongli-hro.tycg.gov.tw/cp.aspx?n=12618 (「規費 250 元,本人親自辦理」)。
3. 沒有憑證也可走**紙本郵寄/臨櫃**,但規費較高(預查 300/設立 1,000)且郵寄來回吃天數,時間緊不建議。

## 4. 關鍵決策項建議

### 4.1 資本額(建議:50 萬)
- 法規:2009 年起無最低資本額,只需「足敷設立成本」;10 萬與 50 萬的**規費完全相同**(都是最低級距 1,000/線上 700),驗資費也幾乎不變。
- 差異只在**盡調觀感**(此段為判斷,非法規):賣 B2B 軟體給券商/金融業,對方採購與法遵會看登記資本額;10 萬元在金融業供應商盡調上偏「個人工作室」訊號,50 萬是小公司常見門面下限(100 萬更穩,但錢要真的存入並凍結到設立完成)。資金設立後即可動用作營運資金,不是沉沒成本。
- 成本差異:僅機會成本(存入~設立核准約 1–2 週資金凍結)。

### 4.2 登記地址(建議:商務中心借址)
- **自宅登記**:0 月費,但①房屋稅從自用住宅 1.2% 變營業用 3%(可按營業面積比例拆分)、地價稅與水電費率可能調整 ②地址公開於商工登記 ③住宅區土地使用分區限制部分行業。純軟體業通常可過,但稅負變動+隱私是主要代價。(常識整理,實際稅率以稅捐處核定為準——標:未逐條查官方)
- **商務中心借址**:台北行情 **月 1,500–3,500 元**(年約 2.5–4 萬),含收信代收;之後可隨時辦遷址變更登記(變更規費 1,000/線上 700)。來源:CBC Space https://content.cbcspace.com/487/ (「1,500 到 3,500 元」);ezstartup https://ezstartup.cc/article/address/startup-address-fee.html (「2,000~3,500 元」)。
- 提醒:選有「合法出租+可開立發票+國稅局勘查配合」的商務中心;國稅局稅籍勘查過不了會卡稅籍。

### 4.3 營業項目代碼(資訊軟體/稽核 SaaS 建議組合)

|---|---|---|

## 5. 名稱預查撞名檢查(2026-08-02 實查)

查詢方法:經濟部商工登記公示資料開放 API(`data.gcis.nat.gov.tw`,同 findbiz 資料源),以特取關鍵字查「核准設立」現存公司。判準:依《公司名稱及業務預查審核準則》,公司名稱是否相同以**特取名稱逐字比對**,字數或用字不同即非相同名稱(近似但不同字原則上可並存)。最終仍以商業發展署預查核駁為準。

| 候選 | 實查結果 | 可用性判斷 |
|---|---|---|
| 圖靈守門 | 無「圖靈守門」;「圖靈」系多家(圖靈創投/圖靈數位等)但特取皆不同 | ✅ 高(特取四字無同名) |
| 可信智能 | 無;近者「可信有限公司」「可信智慧整合有限公司」 | ✅ 中高(特取逐字不同;「可信」家族多,審查員裁量近似的殘餘風險) |
| 守門人科技 | 無「守門人」;近者「守門者有限公司」「守門員科技管理顧問有限公司」 | ✅ 中高(一字之差依準則可過,品牌混淆自行斟酌) |
| 昆騰閘門 | 無「昆騰閘門」;「昆騰」系 6 家(臺灣昆騰/昆騰企業等) | ✅ 中(特取不同可過;昆騰=Quantum 音譯,商標面較擁擠) |
| 馬克戴利 | 無任何含「馬克戴利」 | ✅ 高(且=MarketDaily 音譯,品牌一致) |
| 量子守門 | 無任何含「量子守」 | ✅ 高 |
| **衡鑑科技**(自提) | 無任何含「衡鑑」 | ✅ 高(衡=衡量、鑑=稽核鑑識,唸起來像老牌檢驗機構) |
| **核真科技**(自提) | 無任何含「核真」 | ✅ 高(核=audit、真=truth,直白扣「LLM 可靠層」) |
| **信衡科技**(自提) | 「信衡股份有限公司」已存在(台北,2016) | ❌ 特取「信衡」撞名,放棄 |
| (備位自提)準衡 | 「上準衡器」「恒準衡器」等,特取不同 | ⚠️ 中(可過但易被聯想成衡器業) |

- 預查一次可填多個備選名稱(依序核給第一個可用者),建議一案帶 3–5 個候選一次過。
- **英文名**:公司英文名稱不在經濟部預查範圍,對外品牌可自由使用(如 **QuorumGate Inc.**、TuringGate Inc.、VeriGate Inc.);僅在辦「出進口廠商登記」時需向國際貿易署做英文名稱預查。中文登記名與英文品牌不必對應。
- 商標是另一條線(智慧局),公司名稱核准≠商標權;定案後建議同步申請商標(未在本次範圍)。

## 7. 老闆必須提供/決定的清單(一次列全)

**決定**:
1. 公司中文名最終順位(建議預查一案填 5 個:馬克戴利→量子守門→衡鑑→核真→圖靈守門,順位可換)
2. 資本額(建議 50 萬;要能實際存入)
3. 登記地址(自宅 vs 商務中心;商務中心要挑好並簽約)
4. 自辦 vs 代辦(建議代辦;選大禹 8,000 全包或 Simpany 綁記帳 8,500+2,000/月,順便解決記帳)
5. 營業項目組合(§4.3 表,可照抄)
6. 對外英文名(QuorumGate Inc. 等,不需登記)

**提供/親自做**:
1. 身分證正本(辦自然人憑證,若還沒有;250 元,當場)
2. 身分證影本+印章(公司大小章代辦可代刻)
3. 親跑銀行 1 次:開「○○有限公司籌備處」帳戶+存入資本額(帶預查核准函、雙證件、大小章);設立後再 1 次轉正式戶
4. 委任書/章程親簽(1 次,或線上憑證簽)
5. 登記地址文件:租約或使用同意書+房屋稅單影本(自宅時)

## 8. 總成本估算(一次性)

| 項目 | 自辦 | 代辦(全包,如大禹) |

| 名稱預查 | 150(線上) | 含 |

| 會計師驗資 | ~3,000–5,000 | 含 |
| 大小章刻印 | ~500–1,500 | 含 |
| 代辦服務費 | — | 8,000(特惠價,全包) |
| 自然人憑證 | 250 | 250(線上簽才要) |
