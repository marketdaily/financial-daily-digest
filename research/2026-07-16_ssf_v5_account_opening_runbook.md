## ⚠️ TL;DR（先讀這段，其餘是展開）

1. **SSF 走「期貨戶」，不是證券戶。** 只做 SSF 只需開**永豐期貨**的期貨戶 + 簽期貨那一路，不必開證券戶。[高]
2. **最大閘門是「中華民國稅務居民身分」**，不是文件。永豐證券/期貨**線上開戶白紙黑字限「僅具中華民國稅務居民身分之本國自然人」**。Delvin 長住澳洲、若某課稅年度回台 <31 天且生活經濟重心在澳洲 → 很可能被認定**非稅務居民** → 線上開戶字面上被擋，恐須臨櫃。[高]
3. **開戶當下高度依賴台灣手機 OTP**；澳洲門號收不到台灣券商簡訊是海外遠端開戶最常見死點。[高/低]
4. **但 Shioaji API 日後「每天下單登入」不靠簡訊**——靠 API Key + Secret + 本機 `.pfx` 憑證。裝好之後在澳洲跑程式交易不需台灣簡訊。海外反而順。[高]
5. **最穩路徑：回台一次把「開戶+交割戶+憑證+API簽署」全辦完，回澳洲用 API 常態交易。** 全遠端並非不可能，但成敗全繫於永豐對「非稅務居民/海外IP/海外門號」的**個案政策**，必須先打客服問清三關再賭。[綜合判斷]
6. **開工前第一件事＝打永豐客服問 F 段 8 題**（尤其稅務居民資格）。文件都備齊也可能因這一條卡住，先問再備件。

## A. 帳戶類型釐清（別開錯戶）

| 事實 | 信心 | 來源 |
|---|---|---|
| SSF（股票期貨/個股期貨）是 TAIFEX 掛牌的**期貨商品**，必須用**期貨帳戶**交易，不是股票戶 | 高 | TAIFEX 商品頁 |
| 永豐金證券（SinoPac Securities / SinoTrade）與**永豐期貨**（SinoPac Futures，台北市重慶南路一段2號8樓）是**不同法人、不同帳戶**。SSF 的受託開戶主體是**永豐期貨** | 高 | spf.com.tw / sinotrade.com.tw |
| Shioaji 同一組 API 同時支援證券與期貨：`api.stock_account`（`StockAccount`）、`api.futopt_account`（`FutureAccount`）。**SSF 下單走 `futopt_account`** | 高 | Shioaji 官方文件 |
| 證券與期貨在 Shioaji **各別簽署、各別測試**；只開期貨戶並只簽期貨那份，就能用 API 交易 SSF，不必為 SSF 去開證券戶 | 高 | sinotrade.github.io terms 頁 |

**→ 本案要開的是「永豐期貨的期貨戶」。**（若日後也想 API 買現股才需另開證券戶。）

## B. 開戶必備文件清單（本國自然人 · 永豐期貨線上開戶）

**資格**（線上開戶預設）：[高]
- 未曾在永豐期貨開過期貨帳戶
- 限中華民國自然人、**20–70 歲**
- **須具中華民國稅務居民身分**（← 見 §D 海外閘門）
- 線上開戶**交易額度限制 NT$50 萬**（teach-002 頁載，線上/臨櫃/營業外場所之預設；調高須本人親辦）[中]
  - ⚠️ 校正紀錄：初稿誤植為 100 萬並標 [高]——那 100 萬其實是同頁 Q6「海外所得總額 >100 萬須報稅」的無關數字，2026-07-16 驗證者抓出。實際開戶時以永豐開戶頁當下顯示額度為準。
- 外國人不可期貨線上開戶（須居留證+護照+存摺+指定國內代理人）

**必備文件（逐項）**：[高]
1. **身分證**（線上：正反面圖檔）
2. **第二證件**（駕照或健保卡；正反面圖檔）
3. **銀行存摺**（交割/出入金用；上傳**封面圖檔，需本人簽名並加註年月日**）
4. **本人手持身分證及存摺封面的清晰自拍合照**（線上驗證用）
5. **印章**（臨櫃需要；線上以電子簽章取代）
6. 開戶核准後設定**電子交易密碼**（設定完才能交易）

**交割銀行帳戶**：
- 官方未限定必須永豐銀行；綁**既有台灣他行帳戶**是海外者最省事做法（避開新開數位戶的臨櫃驗證風險）。[中]
- 但「MMA 自動入金」便利功能**須永豐銀行出金帳戶**才能申請。[高]
- 線上僅能綁 1 個出入金帳戶；多帳戶（最多 3 個）須臨櫃。[低]
- 通訊地址**不可為郵政信箱**，否則無法委託下單。[高]

## C. 須簽署文件清單

### C-1. TAIFEX 標準期貨開戶文件（全期貨商通用，永豐比照）[高，來源 TAIFEX]
1. 開戶申請書暨信用調查表
2. **期貨交易風險預告書**（須簽章並加註日期）
3. **受託契約（國內期貨受託契約書）**（須簽章並加註日期）
4. 印鑑卡或簽名樣式卡
5. 期貨交易人開戶資格聲明書
6. **非當面委託簽章同意書**（線上/電子委託需要）
7. 代理開戶及從事期貨交易委任授權書（如需授權他人 → 海外可能用到，見 §D）
8. 開戶聲明書

> 永豐期貨開戶契約書（112年1月核定版）內含「壹、風險預告暨同意書」等章節；官方 PDF 為 CID 編碼無法逐條擷取，完整章節以簽署頁實際版本為準。[中]

### C-2. Shioaji API 額外簽署（自動下單必備）[高/中]
- 於永豐**線上「簽署中心」** `https://www.sinotrade.com.tw/newweb/signCenter/S_openAPI/` 簽署 API 條款。
- 簽署中心分**三類分別簽**：**證券 / 國內衍生性商品（期貨）/ 受託（委託）**。**SSF 屬「國內衍生性商品（期貨）」，必須單獨簽期貨那份。**[高]
- 文件正式名稱：**「API 電子交易風險預告書暨使用同意書」**（證券/期貨各一份，期貨版由永豐期貨出具）；精確法遵字樣以簽署中心當下顯示為準。[中]
- **鐵律：API 條款簽署時間必須早於 API 模擬測試時間（先簽後測），順序顛倒測試報告不生效。**[高]

## D. 海外身分閘門（Delvin 專屬 · 本手冊最重要一節）

### D-1. 稅務居民 = 線上開戶的生死線 [高]
- 永豐官方原文：可線上開戶者為「年滿18歲且**僅具中華民國稅務居民身分之本國自然人**」。「僅具」二字同時排除雙重國籍與非稅務居民。
- **居住者 vs 非居住者認定（財政部，有戶籍者）**：一課稅年度內①居住合計滿 **31 天**→居住者；②居住 1–30 天但**生活及經濟重心在台灣**（健保/勞保、配偶未成年子女居住地、財產受僱地綜合判斷）→仍算居住者；皆不符→**非居住者**。
- **對 Delvin**：長住澳洲，若某年度回台 <31 天且重心在澳洲 → 很可能**非居住者** → 線上開戶字面上被擋。**逐年依事實認定，須自行對照或問國稅局。**[高判準／個案未定]
- 永豐官網**沒有**明說「開戶當下人必須在台灣」，但線上流程靠台灣手機 OTP + 雙證件影像；**是否接受澳洲 IP / 澳洲門號完成線上開戶，官網查無明文** [UNVERIFIED] → 打客服問。
- **海外遠端視訊開戶不能假設存在**；官網只有「線上開戶」與「預約臨櫃」二選項。[UNVERIFIED]

### D-2. 台灣手機 OTP —— 開戶當下的死點 [高/低]
- 券商線上開戶「以手機簡訊驗證身分」，且「本人開戶僅能使用本人手機門號」。**開戶當下極可能要求能即時收簡訊的台灣門號。**
- 保留台灣門號實務：中華電信/台灣大/遠傳**預付卡 + VoLTE/VoWiFi + IP 簡訊 App**，海外用 WiFi 可收台灣簡訊；中華電信預付卡可自動展延門號效期。[低]
- **防詐新制陷阱**：高額轉帳、行動支付、Mobile ID 常要求**月租型門號 + 行動網路**，預付卡在海外可能過不了 Mobile ID → 若金流/憑證踩到 Mobile ID，可能得保月租門號。[低，須實測]

### D-3. 好消息 —— Shioaji API 日常登入不靠簡訊 [高]
- 申請 API Key 的雙因子驗證**可用「手機或信箱」**（官方原文），信箱選項意味海外可過，不一定卡台灣簡訊。
- 日後 API 登入 = **API Key + Secret + 本機 `.pfx` 憑證**，不是每次發簡訊 OTP。**一旦裝好，在澳洲跑程式交易不需台灣簡訊。**
- ⚠️ 但**憑證有效期到期更新**時，人在海外能否線上更新、需不需台灣門號/臨櫃，官網未明 [UNVERIFIED] → 列入客服問題。

### D-4. 交割戶的海外坑 [中]
- 優先**綁既有台灣銀行帳戶**（避開新開數位戶臨櫃驗證）。
- 若要新開永豐大戶 DAWHO：counter-authentication FAQ 逐字載臨櫃驗證要求「30 日內攜開戶申請上傳的雙證件正本+開戶手機至任一分行驗證」[高]。**另**，DAWHO 對「據實聲明具外國稅務居民身分者」設有 FATCA/CRS 證明 + 臨櫃辨識機制（DAWHO 確有此機制，但該句不在 counter-authentication 頁、正確出處待補）[UNVERIFIED]。→ 若被系統判為外國稅務居民，新開 DAWHO 恐卡臨櫃。

### D-5. 稅務影響（SSF 導向） [高/中]
- **期貨交易稅**：股票期貨按每次交易契約金額向買賣雙方各課 **10 萬分之 2（0.00002）**，期貨商當日代徵。**不分居住者/非居住者，稅率與代徵相同 → 居住身分不影響期交稅。**[高]
- **股利就源扣繳 21%**：僅在**另外持有現股**時才踩到；**SSF 持有人不領現金股利**（標的除息以契約調整/結算處理），純做 SSF 基本不受此影響。[中高]
- **個人期貨交易所得的所得稅/最低稅負、非居住者期貨所得課稅** → **不確定，須向國稅局/會計師確認，本手冊不給斷言。**[UNVERIFIED]

## E. 線上 vs 臨櫃 · 時間軸

**可全程線上/App**：[高]
- 期貨戶線上開戶（驗證身分→填資料→簽契約，約 6–20 分鐘；免臨櫃免視訊）
- Shioaji API 條款線上簽署中心簽署；API Key/憑證於線上 API 管理頁自助產生

**須臨櫃（或本國人線上不適用）**：[高/中]
- 外國人一律不可線上開期貨戶
- 提高交易額度（超過線上預設 50 萬）
- 綁定第 2、3 個出入金帳戶、變更出金帳戶
- **非稅務居民 → 線上被擋，恐須臨櫃或國內代理人委任路徑**（外國人流程借用，官方未明文，須客服個案確認）[UNVERIFIED]

**時間軸**（保守估）：[中]
- 線上填件 6–20 分鐘 → 審核最快隔日、保守 2–4 個工作天帳戶可交易（須先設電子交易密碼）
- API：簽 API 條款 → 模擬測試（login+place_order，證券/期貨各測、每筆間隔 ≥1 秒）→ 通過後開通正式環境
- 測試時段：**週一至五 08:00–20:00；18:00–20:00 僅限台灣 IP，08:00–18:00 無 IP 限制** → 海外要測選台灣時間 08:00–18:00
- API 開通綜合：帳戶核准後同日至 1–2 工作天內可開通正式環境（官方無明確 SLA）

## G. 開戶後接手點（銜接 playbook §5）

拿到 API Key/Secret + `Sinopac.pfx` 後，技術啟用步驟（login → activate_ca → 查 `futopt_account.signed==True` → 模擬測試 → 轉正式）已在 playbook `2026-07-13_shioaji_yuanta_broker_api_playbook.md` §5 覆蓋；SSF 執行迴路 harness 見 memory `capability_ssf_execution_harness`（DI 暗門已修，等金鑰真跑）。

**最小啟用骨架**（官方文件擷取，SSF 走 `futopt_account`）：
```python
import shioaji as sj
api = sj.Shioaji(simulation=False)          # 測試報告階段用 simulation=True
api.login(api_key="KEY", secret_key="SECRET", subscribe_trade=True, receive_window=30000)
api.activate_ca(ca_path="/path/Sinopac.pfx", ca_passwd="身分證字號", person_id="A1...")  # 下單前必須
assert api.futopt_account.signed is True    # False = 期貨未簽或測試報告未完成
# SSF 合約在 api.Contracts.Futures 底下，用 sj.FuturesOrder(..., account=api.futopt_account) 下單
api.logout()                                 # 2021-08-06 起有連線數限制，收工必登出
```
坑速查：`Sign data is timeout`→校時/調大 receive_window；`signed=False`→回簽署中心補簽補測；Secret Key 遺失無法找回，只能刪舊 Key 重建；下單前沒 `activate_ca` → 不能下單/取帳務。
